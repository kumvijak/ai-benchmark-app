Fixed concurrency

GuideLLM keeps the selected number of parallel request streams active for each selected concurrency. Use this to compare known workload levels like 1, 2, 4, 8, or 16 streams.

Sweep

GuideLLM runs a baseline, a peak-throughput probe, then interpolated request-rate strategies up to the selected max concurrency. Use this to find the saturation point and safe operating range.

Full-run timing includes all request lifetimes. Measurement warmup and cooldown are disabled; the duration limit remains a safety cap.
